# Agile Planning Lab

[![GitHub Issues](https://img.shields.io/badge/workflow-GitHub%20Issues-181717?logo=github)](https://github.com/YanYihann/lab-agile-planning/issues)
[![Status](https://img.shields.io/badge/status-learning%20exercise-blue)](#scope)

A small learning repository for practicing agile planning with user stories, issues, labels, milestones, and a project board.

## What is included

- A reusable GitHub issue template for user stories
- An issue history that can be used to practice backlog refinement
- A lightweight repository for planning exercises without application source code

## Suggested workflow

1. Open the repository's **Issues** tab.
2. Create a user story with the provided template.
3. Add acceptance criteria and enough context for another person to understand the outcome.
4. Apply labels, priority, and a milestone where appropriate.
5. Move the issue through a GitHub Project board from backlog to completion.
6. Close the issue only after its acceptance criteria are satisfied.

## User-story format

```text
As a [role]
I need [capability]
So that [benefit]

Acceptance criteria:
- Given ...
- When ...
- Then ...
```

## Repository structure

```text
.github/
└── ISSUE_TEMPLATE/
    └── user-story.md
README.md
```

## Scope

This repository documents a planning exercise; it is not a deployable software product. The issues and project board are the primary artifacts.
